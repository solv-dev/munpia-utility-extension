# 문피아 작품 분석 유틸리티 (Munpia Utility Extension)

문피아(Munpia) 웹소설 페이지에서 회차별 지표와 작품 전체 수익을 정밀하게 분석해 주는 크롬 확장 프로그램(Manifest V3)입니다.

---

## 🚀 주요 기능

### 1. 회차별 반응률, 직전 대비 이탈률 및 1화 대비 잔존율 단일 캡슐 인라인 분석
* 회차 목록의 `댓글 XX` 바로 뒤에 정갈한 단일 캡슐 틀(`[ ♥ X.XX% │ ↘ X.XX% │ 🎯 X.XX% ]`)로 연결
* **좋아요 반응률 (♥)**: `(좋아요 수 / 조회수 or 구매수) × 100%`
* **직전 대비 이탈률 (↘ / ↗)**: 화면 정렬순과 무관하게 이야기 흐름상 직전 연재분(`N - 1화`)과 비교하여 정확한 증감률 산출
* **1화 대비 잔존율 (🎯)**: 1화 조회수 대비 각 회차의 조회수/구매수 비율 및 마우스 호버 시 누적 이탈률 툴팁 표시
* **컴팩트 일체형 프레임**: 텍스트 라벨을 초소형 정밀 아이콘으로 대체하고 세 수치를 하나의 틀로 묶어 가로 공간 절약 및 가독성 극대화
* **페이지 경계 완벽 대응**: 문피아 내부 `chapters` API 백그라운드 프리페치로 2페이지 31화, 3페이지 61화 등에서도 직전 회차 데이터 기반 100% 이탈률 및 1화 대비 비율 표시

### 2. 무료 조회수 / 유료 구매수 전 회차 정밀 합산
* 작품 상단 '작품등록일' 바로 아랫줄에 단조롭고 정갈한 순정 스타일로 표시
* 화면에 렌더링된 30개 회차에 구애받지 않고, 1화부터 완결화까지 **전 회차 무료 조회수 및 유료 구매수를 100% 정밀 집계**

### 3. 추정 매출 및 출판사/작가 3대 정산액 (세후 순수익) 분석
* **추정 매출**: `전체 유료 구매수 × 100원`
* **플랫폼 수수료**: `매출의 37%`
* **출판사 정산 (작가 몫 세전 & 원천징수 3.3% 세후 순수익)**:
  * **90%**: 출판사 10% : 작가 90%
  * **80%**: 출판사 20% : 작가 80%
  * **70%**: 출판사 30% : 작가 70%
* 정산 카드 형태로 상단 대시보드 좌측에 깔끔하게 배치

### 4. 작품 종합 퀄리티 지수 ($Q_{total}$) 대시보드 (신규 v0.6.0)
* 상단 출판사 정산 우측 빈 공간에 **[작품 종합 퀄리티 (Q-Score)]** 카드 나란히 렌더링 (`display: flex; gap: 16px;`)
* **듀얼 트랙(Dual-Track) 분기**:
  * **[Track B: 유료 표준]** (유료 회차 10개 이상): 최신 48시간 완충 버퍼 제외 후 최근 $K=20$개 슬라이딩 윈도우 잔존율($r$), 중위 좋아요율($E_L$), 중위 댓글 몰입도($E_C$) 종합 평가
  * **[Track A: 무료 기반]** (유료 회차 10개 미만): 무료 연재 구간(20~45화) 기반 잔존율($r_{free}$) 및 중위 좋아요율($E_L$) 종합 평가
* **대시보드 메트릭**: 메인 $Q_{total}$ 점수(100점 만점), 회당 유지율($r$), 중위 좋아요율, 중위 댓글율, 표본 구간 일목요연 표시

### 5. 회차별 퀄리티 스코어 ($q_k$) 행 단위 주입 (신규 v0.6.0)
* 회차 목록 메타 캡슐 틀 옆에 `[Q 82]` 색상별 뱃지 주입
  * **85점 이상**: 초록 계열 (`#22c55e`)
  * **70점 ~ 84점**: 파랑 계열 (`#3b82f6`)
  * **70점 미만**: 주황 계열 (`#f97316`)
* 1화 및 무료->유료 전환 회차 자동 판별(유지점수 제외 가중 보정)
* 마우스 호버 시 **직전대비 유지점수**, **좋아요점수**, **댓글점수** 세부 점수 툴팁 제공

## 🛠 설치 방법 (개발자 모드)

1. 이 저장소를 로컬 컴퓨터에 Clone 하거나 ZIP 파일로 다운로드합니다.
   ```bash
   git clone https://github.com/solv-dev/munpia-utility-extension.git
   ```
2. Chrome 브라우저를 열고 주소창에 `chrome://extensions/` 입력 후 접속합니다.
3. 우측 상단의 **[개발자 모드]** 스위치를 켭니다.
4. 좌측 상단의 **[압축해제된 확장 프로그램을 로드합니다]** 버튼을 클릭합니다.
5. 다운로드한 `munpia-utility-extension` 폴더를 선택합니다.
6. 문피아 소설 상세 페이지(`https://novel.munpia.com/...` 또는 `https://www.munpia.com/novel/detail/...`)에 접속하여 지표를 확인합니다.

## 📂 프로젝트 구조

```text
munpia-utility-extension/
├── ARCHITECTURE.md          # 시스템 아키텍처 및 버전 히스토리
├── manifest.json            # Chrome Extension Manifest V3 설정
├── icons/                   # 확장 프로그램 아이콘
└── src/
    ├── background/          # 서비스 워커
    ├── content/
    │   ├── core/            # 코어 엔진 (PageWatcher, ChapterDataProvider, DomUtils 등)
    │   ├── features/        # 기능별 모듈
    │   │   ├── chapter-like-ratio/   # 회차별 반응률/이탈률 및 스타일
    │   │   └── novel-summary-stats/  # 상단 조회수/구매수/정산액 요약
    │   └── loader.js        # ES 모듈 동적 로더
    └── popup/               # 확장 프로그램 팝업 UI
```
